# 🎧 Headphone Store

A modern and responsive headphone e-commerce website built using HTML, CSS, Bootstrap and JavaScript.

The website provides a complete basic shopping experience where users can browse products, view product details, add products to the cart, update quantities, remove products and proceed to checkout.

---

## 🌐 Features

### 🏠 Home Page
- Attractive hero section
- Navigation bar
- Product section
- Responsive design

### 🛍️ Shop Page
- Displays headphone products
- Product cards
- Product images
- Product name and price
- Add to Cart button
- Product price sorting

### 🎧 Product Details
- View individual product
- Product image
- Product name
- Product price
- Product availability
- Select product quantity
- Add product to cart

### 🛒 Shopping Cart
Users can manage their cart easily.

- Add products
- Remove products
- Increase quantity
- Decrease quantity
- View product price
- Calculate subtotal
- Calculate total price
- View all selected products

### 🧾 Cart Popup
The navbar contains a cart popup.

It displays:

- Product image
- Product name
- Product quantity
- Product price
- Remove button
- Cart subtotal
- VIEW CART button
- CHECKOUT button

### 💾 LocalStorage
Cart data is stored in browser LocalStorage.

Because of LocalStorage, cart products remain available even after refreshing the page.
